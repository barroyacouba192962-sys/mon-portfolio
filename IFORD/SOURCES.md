## Retélécharger les PDF

```bash
bash IFORD/telecharger_sujets.sh
```

Pour les autres sessions (2014, 2016-2022, 2024-2026), seules les plateformes ci-dessus
(Kamerpower, Edukamer, Scribd…) en proposent, à télécharger à la main.

> de les redistribuer dans l'application.
